# What's where

```
index.html               The page shell: header, settings dialog, feedback tab
src/
  app.js                 Screens, state, events (the only file that touches the DOM)
  tasks.js               Three sets of 12 questions, the five kinds, twists, truths, sources
  scoring.js             Judging, counts, herd rate, Wilson range, shift, import checks, share links
  charts.js              Results-over-time chart and typeset equations
  aq10.js                AQ-10 items and published scoring key
  store.js               localStorage, guarded so blocked storage still works
  styles.css             Light and dark tokens, layout, components
assets/
  icon.svg               The icon (source for every size)
  icon-32/180/512.png    Generated by npm run shots
tests/
  scoring.test.js        Unit tests (node:test)
  ui.spec.js             UI tests (Playwright)
  screenshots.mjs        Regenerates docs/screenshots and icons
docs/
  SYSTEM-DESIGN.md       Architecture, decisions, limits
  INSTRUCTIONS.md        Use, run, test, deploy
  MANUAL-REVIEW.md       What tests can't check
  RESEARCH.md            Cited review of existing measures (CRT, AOT, NCS, BSR, Asch)
  PROMPTS.md             Prompt log
  screenshots/           Light, dark and phone screenshots
DoYouThinkOnYourOwn?.md  The project spec, with decisions and definitions
playwright.config.js     Browsers and viewports for UI tests
package.json             Scripts (start, test, test:ui, test:all, shots)
```
